# Atlas 参考工作台

两个工作台使用 React、TypeScript、Vite 和从 `vendor/arc-ui/` 复制的 Arc UI 组件，图标使用 lucide-react。依赖版本写在 `package.json` 中，锁文件位于 `app/package-lock.json`。

## 启动与构建

在 `app/` 目录执行：

```powershell
npm.cmd install
npm.cmd run dev:web
```

Web 开发地址为 `http://127.0.0.1:5211/`。Motion 在另一个终端启动：

```powershell
npm.cmd run dev:motion
```

Motion 开发地址为 `http://127.0.0.1:5212/`。各自构建：

```powershell
npm.cmd run build:web
npm.cmd run build:motion
```

产物分别在 `app/web/dist/`、`app/motion/dist/`。每个目录可直接作为静态网站部署，支持部署到子路径。导航使用 URL hash，静态服务器无需配置页面回退。构建需要仓库的 `content/` 和可读取的 Demo 目录链接；产物中的 Demo 是实际文件，可脱离源码目录部署。

## 组织方式

| 目录 | 用途 |
| --- | --- |
| `web/` | Web Atlas 的 HTML 入口、Vite 配置与独立产物 |
| `motion/` | Motion Atlas 的 HTML 入口、Vite 配置与独立产物 |
| `shared/` | 导航、浏览、详情、播放器、文档阅读、收藏和比较 |
| `build/config.ts` | 按入口读取所属库的 JSON、Markdown 和文件目录，保留资源相对路径 |
| `arc/` | 复制的 Arc UI 基础 Token、动效 Token、组件和 MIT 许可证 |
| `screenshots/` | 两个工作台的桌面和手机截图 |

两个入口只读取各自库的内容。每次构建将所属库复制到产物的 `content/`，保留 `demos/`、`previews/`、`docs/`、`prompts/`、`agent/` 和运行时的相对层级。浏览页的数据、文档正文和文件目录在构建时读取；页面功能在浏览器中运行。

## 页面组织与设计

固定侧栏组织总览、案例、巧思、素材、文档、收藏、比较和创作工具。桌面上保留导航位置，手机上通过菜单打开。总览以参考选集和三类内容入口为主；列表用封面、摘要和标签帮助识别作品，搜索、筛选与排序集中在列表上方。

详情先显示可操作的 Demo，再通过「完整拆解」「Prompt」「资料与关联」切换阅读任务。长拆解保留章节目录，字段随条目内容展示，空字段省略。文档使用分组目录、正文阅读和章节目录，搜索覆盖文档标题、路径及正文。这样可以在同一条目里完成观察、理解和取材，长文不会挤占 Demo 的操作空间。

两库共用灰绿色的界面语言、字号、间距和交互组件。Web 默认浅色，Motion 默认深色；两者均可改为浅色、深色或跟随系统，主题选择保存在浏览器中。

Web 的浏览操作以页面结构为中心：案例可切换适应尺寸、1440px 桌面和 390px 手机尺寸；有原站截图时可并排查看。巧思通过来源案例中的定位记录，执行准备动作、滚动到目标并高亮。Motion 的观察以时间为中心：案例和巧思连接 Demo 的 `__motion`，提供时间轴、节拍和能量曲线，按运行时回报提供画幅与声音控制。素材使用自己的样例入口、样例目录、画廊或原文工作流。

## 使用

- 搜索词以空格分隔，每个词都需匹配；条目搜索覆盖完整 JSON 中的标题、摘要、标签和拆解。
- 分类筛选、排序、列表页码、详情标签页、来源案例、素材样例与文档位置保存在 URL 中。浏览器前进、后退恢复对应页面和列表状态。
- 三类条目均可收藏。收藏页可导出或导入原库格式的 JSON，导入时合并本库已知条目。
- 在案例封面或详情中加入 2–3 个案例，打开比较页逐项对照拆解。
- 实现 Prompt 的复制会一并保留负向约束；视频生成 Prompt 和负向约束也可单独复制。
- 「资料与关联」提供现成 Agent JSON 资料包、关联条目和本地文档入口。
- 文档中的本地 Markdown 链接进入阅读页；图片和其他文件按原文所在目录解析。图片可点击打开原图。

Motion 快捷键：空格播放或暂停，左右方向键移动 1 秒，`[`、`]` 跳转节拍，Home/End 定位起止，M 切换声音，F 切换全屏。输入控件获得焦点时使用控件自身的按键行为。

设计实验室、节奏实验室和 Agent 工作流是预留入口。页面内说明各自的用途，案例详情可直接复制 Prompt 和下载资料包。
